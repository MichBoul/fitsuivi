    Importer depuis Huawei Santé

    Huawei Santé n'a pas d'API publique : l'import se fait à partir d'un export de tes données (fichier CSV ou JSON). Le fichier est lu uniquement sur cet appareil ; seules les pesées sont enregistrées, les pas et calories sont seulement affichés.

    Obtenir l'export

    1. Ouvre les réglages de ton compte HUAWEI (Paramètres du téléphone → ton nom / Compte HUAWEI, ou l'espace « Compte HUAWEI » sur le web).
    2. Va dans Confidentialité (parfois « Centre de confidentialité » ou « Gestion des données »), puis choisis Demander une copie de vos données / « Télécharger vos données ».
    3. Coche Santé (Huawei Santé / Health) et valide. Un mot de passe peut être demandé pour protéger l'archive : note-le.
    4. Quand l'export est prêt (notification ou e-mail, parfois après quelques jours), télécharge l'archive ZIP et décompresse-la avec ce mot de passe.
    5. Repère le fichier CSV ou JSON qui contient les données de santé (poids) et sélectionne-le ci-dessous.

    Le chemin exact dans les menus peut varier selon la version de Huawei Santé, d'EMUI/HarmonyOS et le pays.
